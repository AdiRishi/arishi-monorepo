This starter connects a web application, internal Workers, and shared Cloudflare resources through one typed Alchemy program. Effect services implement the application behavior; Alchemy owns deployment, bindings, and local runtimes.

The included CSV profiler exercises the complete path from browser upload to background processing and source download. Replace that example with your own application once you understand the graph.

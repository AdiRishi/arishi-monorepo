This repository connects a web application, internal Workers, and shared Cloudflare resources through one typed Alchemy program. Effect services implement the application behavior; Alchemy owns deployment, bindings, and local runtimes.

It currently hosts one web app, Adishwar Rishi's personal website in `apps/web`.
